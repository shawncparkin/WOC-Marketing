
# Cloud Evaluation for WOC

**Owner:** Kallie Northrop — Solution Designer  
**Project:** Wasatch Outfitters Collective (WOC)

## 1. Purpose

This evaluation considers how cloud technology could support WOC's proposed marketing information system. The goal is to determine whether cloud-based infrastructure can help WOC organize marketing data, monitor campaign performance, and calculate customer acquisition cost (CAC).

## 2. Google Cloud Experience

As part of the Google Cloud virtual machine lab, I created a virtual machine using Google Cloud Console and the command line. I also deployed an NGINX web server and accessed its welcome page.

This exercise demonstrated how a business can use cloud infrastructure to host a service without purchasing and maintaining its own physical server.

## 3. Business Fit for WOC

Cloud technology could support WOC by providing infrastructure for a centralized marketing information system.

A centralized system could help WOC:
- Combine marketing spending information from different advertising channels.
- Organize customer and sales data.
- Calculate customer acquisition cost (CAC).
- Compare campaign performance.
- Give marketing managers easier access to performance information.

This would address WOC's current problem of tracking advertising expenses through inconsistent and disorganized methods.

## 4. Cost and Scalability

Cloud infrastructure can reduce the need for a business to purchase and maintain its own physical servers. It also provides flexibility because computing resources can increase or decrease as business demand changes.

For WOC, this could make it easier to begin with a smaller system and expand as marketing data and business needs grow.

However, cloud services still have ongoing costs. WOC would need to monitor usage and choose resources that fit its actual needs.

## 5. Security and Risks

Using cloud infrastructure also introduces security responsibilities. WOC would need to protect customer information, control employee access, and maintain secure data practices.

Cloud security is a shared responsibility between the provider and the organization. WOC would still need appropriate access controls, monitoring, and data protection procedures.

## 6. Recommendation

I recommend that WOC consider starting with an affordable, entry-level cloud configuration. This would allow the company to access cloud infrastructure without committing to expensive resources before they are needed.

If WOC experienced significant growth, such as a tenfold increase in customers, it might need a more expensive configuration with additional cloud resources.

The main trade-off is that lower-cost configurations may provide lower performance. WOC should balance affordability with the performance and scalability required by its marketing information system.

## 7. Limitations and Assumptions

The Google Cloud VM exercise demonstrated basic cloud infrastructure and web-server deployment. It did not create a fully functioning WOC marketing database or connect live advertising and sales information.

The recommendation is therefore based on the potential business benefits of cloud infrastructure rather than a completed production system.
