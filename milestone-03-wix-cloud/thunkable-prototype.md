# Thunkable WOC Marketing App Prototype

**Owner:** Kallie Northrop — Solution Designer  
**Project:** Wasatch Outfitters Collective (WOC)

## 1. Prototype Overview

This prototype is a mobile marketing performance app created using Thunkable. It demonstrates how WOC's marketing team could view campaign performance information in one place.

## 2. Marketing Workflow Supported

The app supports the process of reviewing marketing campaign performance across different advertising channels.

Users can select a marketing channel:
- Instagram Ads
- Google Search
- Email Newsletter
- Local Radio

After selecting a channel, users tap "View Performance" to navigate to a results screen.

## 3. Performance Information

The results screen displays simulated information about:
- Marketing spend
- Conversions
- Customer acquisition cost (CAC)

This demonstrates how combining marketing data could help WOC compare campaign performance and make more informed decisions.

## 4. Business Value to WOC

The prototype illustrates how a centralized marketing dashboard could reduce the need to manually combine information from multiple spreadsheets.

It could help WOC:
- Compare performance across marketing channels
- Monitor campaign spending
- Understand customer acquisition costs
- Make more data-driven marketing decisions

## 5. Prototype Limitations

The app uses simulated performance data rather than live connections to WOC's marketing platforms or sales systems. A future version would need to connect to reliable data sources to provide actual campaign results.
