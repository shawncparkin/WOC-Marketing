# WOC Marketing Information Systems Consulting Project

## Project Overview
This University of Utah consulting project examines how Wasatch Outfitters Collective (WOC) can connect its marketing, customer, and sales data to improve campaign reporting, evaluate marketing effectiveness, and support better business decisions.

## Business Problem
WOC's marketing data is spread across multiple channels, while customer and sales information is not fully connected. This makes it difficult to measure true customer acquisition cost, attribute sales to campaigns, and compare marketing performance reliably.
